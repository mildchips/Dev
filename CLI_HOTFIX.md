# v0.3.7 — CLI hotfix 1

23.11.2026. Исправлен локальный ввод пароля. Версия приложения остаётся 0.3.7; базы, роли и формат паролей не менялись. Новые зависимости не требуются. Production/live/macOS готовность не заявляется.

## Причина сообщения пользователя

`ValueError: password confirmation mismatch` возникал до записи пользователя, когда пароль и подтверждение не совпали. Вставленные сразу следующие shell-команды продолжили выполняться: после ошибки владельца терминал перешёл к паролю менеджера. Первая запись владельца в этом случае не создана.

## Что исправлено

- Несовпадение: русское сообщение и повторный ввод обоих значений в той же команде.
- Длина: 12–256 символов для пользователя, 16–256 для копии; проверка до подтверждения. Значения не обрезаются и не нормализуются.
- Ctrl+C/EOF: понятное завершение без traceback, код 130. При отмене на вводе пароля пользователь не создаётся.
- Занятый логин: сообщение до запроса пароля, код 2. Прежний пароль/права сохраняются; повторный `--owner` не повышает роль менеджера.
- Невозможность скрыть ввод: отказ вместо fallback с показом пароля.
- Успех: явное сообщение «Пользователь создан» и прежний JSON с ID.

Изменён runtime-файл только `saas_lab/__main__.py`. Добавлены 9 CLI tests, эта инструкция, уточнение README и актуальный манифест/метаданные упаковки.

## Как обновить существующую папку

Остановить текущий ввод/процесс через Ctrl+C. Заменить только файл `saas_lab/__main__.py` предоставленным исправленным `__main__.py`. Не заменять всю папку `saas_lab` одним файлом. Пользовательские базы в `~/.aipo_saas_lab` и `~/.ai_profit_office` сохраняются; удаление/сброс не требуется. Новая установка зависимостей не нужна.

Затем выполнять команды по одной, дожидаясь успеха каждой:

```bash
python -m saas_lab user synthetic-owner --owner
```

Дважды ввести одинаковый придуманный пароль длиной 12+ символов. При вводе нет ни букв, ни звёздочек. Проверить раскладку и Caps Lock. Пароль не присылать в чат.

```bash
python -m saas_lab user synthetic-manager
```

Если менеджер ранее уже создался, повторная команда сообщит об этом и ничего не изменит. Использовать прежний пароль. Если он забыт, этот фикс не добавляет сброс пароля или обход входа.

```bash
python -m saas_lab.server
```

Открыть http://127.0.0.1:8766 и войти как synthetic-owner с его паролем. Создать вымышленный магазин и пригласить менеджера. Это отдельная лаборатория; обычный финансовый интерфейс по-прежнему запускается прежним способом на порту 8765.
