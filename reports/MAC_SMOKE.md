# L01 · Проверка CLI Hotfix 1 на MacBook

Статус — ожидается запуск на Mac. Использовать checkout `mildchips/Dev` с CLI
Hotfix 1. Записать SHA, macOS, архитектуру и версию Python. В отдельном venv
установить `requirements-lock.txt`. Для всей сессии использовать новую папку.

```bash
aipo_smoke="$(mktemp -d)"
python -m saas_lab --db "$aipo_smoke/lab.db" user synthetic-owner --owner
python -m saas_lab --db "$aipo_smoke/lab.db" user synthetic-manager
```

- У owner намеренно ввести несовпадающие вымышленные значения, увидеть повтор
  запроса и создать пользователя. На экране нет символов пароля.
- У manager нажать Ctrl+C при подтверждении. Код 130, без traceback и созданной
  записи. Затем повторить команду и создать пользователя.
- Попытаться повторно создать manager с `--owner`. Код 2 до ввода пароля,
  прежний пароль и роль действуют.
- Отдельные терминалы: `python -m saas_lab.server --db "$aipo_smoke/lab.db"`
  и `AI_PROFIT_DB="$aipo_smoke/finance.db" bash start.sh`. Передать путь
  временной папки второму терминалу. Проверить локальные страницы на 8766 и 8765.
- В lab войти обоими пользователями, проверить роли и остановить процессы.
  Приложить снимок со статусом теста, без паролей и персональных данных.
- Для фактического дефекта сохранить шаги, ожидаемый и фактический результат,
  версию и код выхода в Issue. До Mac-прогона фото и Issue отсутствуют.
