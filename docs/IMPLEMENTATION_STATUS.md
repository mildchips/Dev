# Реализовано / не реализовано · v0.3.2 · 18.11.2026

## В коде реализовано

- Локальная авторизация по парольной фразе, hashed sessions, CSRF / origin / host checks, logout и ограничения на попытки входа; базы с разрешениями 0600.
- Запрет доступа к бухгалтерской информации при отсутствии локальной аутентификации.
- Сохранён модуль Vault: AES-256-GCM, отдельные магазины и 4 уровня остановки; секреты только в CLI.
- Поддержка обычного и датированного COGS; по датам нет будущего lookahead.
- Поиск потенциальных перекрытий файлов, блокирование вклада в прибыль при подозрении на двойной учёт, возвратах за пределами периода, отсутствии себестоимости.
- Сценарный расчёт на явных предположениях, без автозаявления об экономии.
- Отдельный трекер действий, локальный аудит изменений, дополнительное подтверждение удаления магазина.
- UI с тремя режимами + сценарии + история затрат + действия + логин.
- Автоматические тесты и mock-fetch визуальная проверка browser UI.

## Не реализовано

- Проверка реальных ключей и любая загрузка данных через WB/Ozon API.
- SaaS RBAC и межклиентская авторизация (есть только **один локальный оператор**).
- Cloud KMS, PostgreSQL, очередь задач, распределённые лимиты, централизованное аварийное выключение активных воркеров.
- Автоматическая подготовка претензий WB/Ozon и подтверждённые суммы возвратов.
- Сверка с внешним источником, полноценная историческая партия/COGS каждого возврата.
- Финансовый causality framework, A/B, автоматическая оценка 100 000 ₽/мес.
- LLM агент, биллинг, мультиарендная платформа, публичный SaaS.

**Статус:** локальная исследовательская версия. Не подключать публичный порт, не делать никаких финансовых гарантированных обещаний от имени продукта.
