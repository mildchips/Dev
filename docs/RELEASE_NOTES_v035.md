# v0.3.5 — Guarded READ ONLY Connector

## Сделано

1. `app/live_connector.py`: HTTPX live POST-транспорт **с выключенной по умолчанию сетью**, фиксированными HTTPS-хостами, блокировкой прокси из окружения, отказом от редиректов, ограниченным чтением ответа и подавлением тела ошибок.
2. `LiveGateway`: два независимых допуска (точная переменная окружения и одноразовый короткий permit), проверка собственного магазина/площадки, vault/stop, реальное потребление попыток, bounded retries для 429/5xx/timeout, автоматическая блокировка ключа при 401/403.
3. `DurableQuota`: файл SQLite с атомарным резервированием квот между локальными процессами, раздельно по магазинам и платформам; ограничение ожидания.
4. Vault: новая метаинформация `expires_on`, сигналы 30/14/7 дней, запрет неизвестной даты окончания Ozon-ключа для live, отключение старых permit при STOP, ROTATE, REVOKE и изменении срока действия; автоматическая миграция схемы vault.
5. `app/live_cli.py`: offline status/preflight/expiries/set-expiry, ручные arm/disarm, отдельный ограниченный canary (сеть только после всех разрешений).
6. Обратная совместимость с v0.3.4: существующая модель данных, финансовое ядро, UI, mock-контракты и тесты не удалены.
7. Новые тесты включают межмагазинную изоляцию, stop посреди пагинации, TCP/HTTP-заголовки через `httpx.MockTransport`, 401/403/429, redirects, лимиты и ротацию.

## Не сделано и не заявляется

- Не были отправлены реальные запросы в Ozon/WB. Реальные кабинеты и ключи не проверены.
- Не подтверждены реальные финансовые схемы, права токенов, временные ограничения API и финансовая сверка.
- Нет production-ready многопользовательского SaaS, OAuth, KMS, PostgreSQL, redis quota, отказоустойчивых очередей.
- Нет гарантии отсутствия ошибок при первом живом подключении.
- Нет автоматического признания прибыли из сырых API-начислений.

## Совместимость

- Python 3.11+; основные зависимости в `requirements.txt` теперь включают `httpx`.
- Vault автоматически расширяется полем `expires_on` и таблицей `live_permits` при открытии существующего каталога.
- Изменение `rotate` без указания `expires_on` очищает старую дату: следующий Ozon live требует указать дату нового токена.
- Для локального запуска keep `AI_PROFIT_ALLOW_LIVE` unset.
