Удаление этой маркировки не является способом включения реального API: сначала нужен проверенный контракт, минимизированные фикстуры и отдельное изменение allowlist/transport.

## Решение по выпуску

GO для локальной синтетической сверки. NO GO для автоматического признания прибыли по настоящим ответам API и для публичного SaaS. Доступность метода в анонсе не доказывает совместимость с кабинетом, права конкретного ключа или правильность финансовой классификации.

WB календарь: функция `moscow_day` учитывает Europe/Moscow; время без timezone отклоняется. Новые отчётные маршруты остаются лабораторными; их интерпретация дат, лимитов и пагинации требует официального контракта. Прежнее ограничение WB 60 секунд/магазин не повышалось. Виртуальные вызовы ReportLab не измеряют реальную производительность и не являются нагрузочным тестом API.
